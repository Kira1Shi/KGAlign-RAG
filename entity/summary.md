# Entity extractor comparison for graph-based RAG hallucination detection

Сравнение методов выделения сущностей на реальных данных RAGTruth и XSum. Экстрактор задаёт множество вершин графа и входит во все метрики выравнивания, поэтому его выбор проверяется эмпирически, а не заимствуется у HalluGraph.

## Установка

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
./download_data.sh
```

`download_data.sh` загружает RAGTruth из репозитория ParticleMedia, разметку галлюцинаций XSum из репозитория Google Research (Maynez et al. 2020) и данные NLTK в каталог `data/`.

## Запуск

```bash
python run_experiment.py content_nouns --n 600 --n-xsum 400
python make_figure.py
```

Доступные методы: `spacy_sm`, `spacy_md`, `nltk_ne`, `noun_chunks`, `nc_clean`, `content_nouns`, `hybrid`.

Извлечённые множества сущностей кэшируются в `cache/<method>.jsonl`, поэтому запуск резюмируем: с флагом `--budget 300` процесс останавливается через 300 секунд, возвращает код 3 и продолжает с того же места при повторном вызове. Это нужно для `nltk_ne`, стоящего 9.3 секунды на контекст против 56 миллисекунд у методов на spaCy.

Результаты дописываются в `results/ner_results.json`, график сохраняется в `assets/fig_ner_comparison.png`.

## Структура

| Файл | Назначение |
|---|---|
| `extractors.py` | Семь экстракторов с единым интерфейсом `extract(text) -> set[str]` и реестр `REGISTRY` |
| `data.py` | Загрузка RAGTruth и XSum, разворачивание `source_info` по типам задач, детерминированная выборка (seed = 17) |
| `run_experiment.py` | Прогон одного экстрактора: плотность графов, AUROC и AU-PRC метрики Entity Grounding, стоимость |
| `make_figure.py` | Сводный график по `results/ner_results.json` |

## Методы

**Фиксированная схема (18 типов):** `spacy_sm` — базовая линия, инструмент HalluGraph; `spacy_md` — та же схема при большей ёмкости модели; `nltk_ne` — та же схема в другой библиотеке (maxent chunker).

**Открытая схема, синтаксические эвристики:** `noun_chunks` — сырые именные группы, верхняя граница полноты; `nc_clean` — именные группы без детерминативов и служебных слов, с лемматизированной вершиной и отброшенными родовыми группами; `content_nouns` — леммы токенов NOUN и PROPN без стоп-слов.

**Гибрид:** `hybrid` — объединение сущностей NER с очищенными именными группами.

Zero-shot NER (GLiNER) и LLM со структурированным выводом в этом прогоне не воспроизведены: веса GLiNER распространяются через Hugging Face, LLM требует внешнего API, а исполняющая среда была изолирована от обоих источников.

## Результаты

RAGTruth, 600 ответов тестового сплита, 39% галлюцинаций. AUROC вычислен по метрике Entity Grounding относительно ручной фрагментной разметки. `nltk_ne` прогнан на вложенной подвыборке из 100 ответов.

| Метод | Сущности контекста, медиана | Пустых графов ответа | AUROC | AU-PRC | мс на контекст |
|---|---|---|---|---|---|
| spacy_sm | 23 | 6.2% | 0.668 | 0.532 | 56 |
| spacy_md | 22 | 6.0% | 0.648 | 0.503 | 65 |
| nltk_ne | 14.5 | 7.0% | 0.616 | 0.394 | 9298 |
| noun_chunks | 66 | 0% | 0.779 | 0.624 | 63 |
| nc_clean | 53 | 0% | 0.801 | 0.697 | 67 |
| **content_nouns** | 63 | **0%** | **0.813** | **0.745** | 57 |
| hybrid | 68 | 0% | 0.808 | 0.729 | 58 |

XSum, 400 рефератов: медиана сущностей реферата растёт с 2 до 6, доля пустых графов падает с 17% до 0%.

Замена экстрактора, не затрагивающая ни метрик, ни агрегации, поднимает AUROC с 0.668 до 0.813 и устраняет пустые графы. Разреженность графов, диагностированная у вопросно-ответной подзадачи RAGTruth и у XSum, оказывается артефактом фиксированной схемы, а не свойством данных.
